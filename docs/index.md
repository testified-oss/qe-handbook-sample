# QE Handbook

Welcome to the **Quality Engineering Handbook**. This site is the single source of truth for our QE practices, strategy, and tooling.

## Structure

This handbook is organized so that **general QE guidance** stays reusable across projects, and **project-specific details** stay isolated:

- **Strategy** (`/docs/strategy`) — universal QE principles, quality models, and the testing lifecycle. Reusable across every project.
- **Guides** (`/docs/guides`) — reusable tooling and test guides that teams can adopt as-is.
- **Projects** (`/docs/projects/example-project`) — project-specific overrides and notes kept separate from general guidance.

## How to use this site

- Start with the **Strategy** section to understand the quality model and lifecycle.
- Jump to **Guides** when you need a concrete process or tool recommendation.
- Check **Projects** for project-specific instructions, exceptions, or local decisions.

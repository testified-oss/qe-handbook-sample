# Quality Model

Our target quality model defines what "quality" means for this handbook and how we measure progress toward it.

## Overview

Drawing from comparable open-source handbooks (IOG Quality Engineering, Infinum QA Handbook, GitLab), we organize quality across maturity levels:

1. **Initial** — ad hoc, reactive testing.
2. **Managed** — defined processes, basic automation.
3. **Defined** — consistent practices across teams.
4. **Quantitatively Managed** — measured and controlled.
5. **Optimizing** — continuous improvement.

## How to use this

Use the maturity model to:
- Assess current project state.
- Identify the next improvement area.
- Track QE maturity over time.

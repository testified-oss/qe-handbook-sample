# Testing Guide

Testing conventions and approaches recommended across projects.

## Approach

- **Shift-left testing** — validate early and often.
- **Automation-first** — prioritize automated checks for repeatable validation.
- **Exploratory complement** — use manual exploration alongside automation.

## Conventions

- Use consistent naming and structure across test suites.
- Keep tests maintainable and readable.
- Version and track test artifacts with the codebase.
